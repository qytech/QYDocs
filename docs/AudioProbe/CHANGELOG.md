# QYAudioProbe 更新日志

## 0.1.0 - 2026-09-22

### 修复
- 修复 GBK→Latin1、UTF-8→GBK 等常见标签乱码；中英混排标题/艺人可正确还原，西欧原文（如 `Csárdás`、`Mêlée`）不再被误改。
- 修复词内异常控制符被当作撇号的问题（如 `Terence Trent D'Arby`、`Lovely Day (7' Sunshine Mix)`）；完整多值分隔保留为 `"; "`。
- 清理私用区引号/脏字符（映射为 ASCII 引号或移除首尾噪声）；`U+FFFD` 不猜测补字，可回退文件名。
- ID3 ISO-8859-1 帧中误写入的 GBK 字节可优先按 Latin-1 反转还原。

### 优化
- 元数据清洗链路统一，批量导出与乱码回归检查工具更稳健。

## 0.0.2-snapshot - 2026-09-17

### 优化
- 接入原生动态库时效性与符号合法性校验机制。
- 优化 JNI 局部引用回收与流式探测稳定性。

## 0.0.1-snapshot - 2026-09-16

### 新增
- 初始版本发布：高性能音频格式嗅探与元数据提取库，支持全格式音频、DSD/SACD、CUE 分轨解析及 HTTP Range 流式嗅探。
