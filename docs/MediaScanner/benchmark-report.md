# QYMediaScanner 扫描与入库性能基准测试报告

本文档记录 QYMediaScanner 结合 Android 数据库持久化管线在数播一体机真机上的端到端性能表现与压测数据，为集成方提供并发配置与硬件资源选型参考。

---

## 1. 测试环境与基准

- **测试设备**：数播一体机真机（4 核 64 位 ARM，Android 12 / API 32）
- **测试语料**：网络 SMB 共享目录挂载，包含 **4,015** 个高规格无损音频文件（DSD、FLAC、WAV、APE、SACD ISO、CUE 分轨等），产出 **4,170** 首音轨
- **数据库管线**：Android Room 批量持久化（单批 300 首，流式批次缓冲队列）
- **指标监测**：外部独立工具每秒采样系统 CPU、GPU 频率与负载、SoC 温度、进程常驻内存（RSS）以及 ART 虚拟机 GC 次数

## 3. 关键结论与集成建议

### 3.1 极佳的端到端吞吐
- 在 `maxWorkers = 4` 配置下，扫描并解析 4,015 个高规格音频文件（含封面提取、标签分析和 CUE 展开）并完整写入 Room 数据库仅耗时 **15.7 秒**（平均每秒处理超过 **265** 首歌曲）。
- 原生探测与数据库写入通过带有缓冲的流式批次队列实现无缝重叠，I/O 等待与数据库持久化完全并行化。

### 3.2 卓越的温控与资源占用
- **CPU 负载轻**：4 线程全速扫描期间，本进程平均 CPU 仅为 26.3%，系统整体 CPU 使用率低于 50%，不会引起系统掉帧或发热卡顿。
- **温度极低**：全负荷扫描期间，CPU 最高温度仅 61.1 °C，温升仅约 2.7 °C，完全无需担心散热不良引发降频。
- **内存无抖动**：采用零拷贝流式回调后，堆内存平稳，常驻内存保持在 204 MB 左右，全程无任何前台 UI 阻塞性 GC。

### 3.3 推荐集成配置

| 场景 | 推荐 `maxWorkers` | 推荐 `batchSize` | 说明 |
|---|---|---|---|
| **数播一体机（4 核 SoC）** | **2 ~ 4** | **300 首** | 平衡扫描速度与能效，实现最快速度建库 |
| **便携 HiFi 播放器（电池供电）** | **2** | **300 首** | 兼顾扫描速度与电池续航，发热控制更优 |
| **外置 USB 移动硬盘 / NAS** | **4** | **300 首** | 充分利用多线程重叠网络及 USB I/O 延迟 |
