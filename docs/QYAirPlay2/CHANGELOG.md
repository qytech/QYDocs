# QYAirPlay2 更新日志

本文档记录 QYAirPlay2 各版本的功能更新与使用变化。

## v0.1.0 - 2026-09-30

- 提供 AirPlay 音频接收与播放，以及歌曲信息、封面和播放进度。
- 支持多手机播放接管，改进暂停与恢复播放。
- 修复手动切歌时的旧曲尾音与短促异音。
- 支持手机调节设备硬件音量，接入时可关闭软件音量。
- 改进断开连接后的封面显示、网络切换和播放异常恢复；手机控制请求失败时保持音乐播放。
- 补充 UDP 319/320 固件配置、ADB 临时设置及验证步骤，详见[接入说明](index.md)。
- 升级后需重新编译所有依赖 SDK 的模块，现有常用方法和双参数音量回调可继续使用。

不同手机与音乐 App 的播放控制能力以实际支持情况为准。

## v0.0.1-snapshot - 2026-09-16

- 初始版本：支持局域网 AirPlay 2 音频接收与播放控制，提供歌曲信息、封面和播放进度。
