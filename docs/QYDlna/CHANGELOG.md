# QYDlna 更新日志

本文档面向集成客户，仅记录当前版本已实现的公开能力和接入边界。`0.0.1-snapshot` 为预发布版本，真实设备互操作结果以客户验收记录为准。

## v0.0.1-snapshot - 2026-09-15

### 当前已实现

- 提供统一入口 `com.qytech.dlna.QYDLNA`，支持单独启动 DMR、单独启动 DMS，以及同时启动 DMR + DMS。
- DMR 支持播放、暂停、停止、上一曲、下一曲、拖动、音量和静音控制。
- 通过 `state` 和 `mediaServerState` 提供播放状态、曲目信息、进度、音量、静音、封面与曲库状态；通过 `events` 或 `setCallback(...)` 接收播放事件。
- DMS 支持发布宿主可读取的本地绝对路径，并供控制点浏览音乐目录。
- 支持前台服务模式，服务类型为 `mediaPlayback`，可用于长时间后台运行。
- 支持通过 `QPlayConfig` 启用 QPlay，并提供 QPlay 状态、队列、音质和歌词信息。
- 支持自定义 DMR 与 DMS 设备描述，以及通过 `libraryInfo` 获取版本和构建日期。

### 接入边界

- Android API 29+，当前仅提供 `arm64-v8a` 原生库。
- `roots` 必须是宿主进程可读取的本地绝对路径，SAF URI 不能直接作为曲库根目录。
- 尚未宣称通过所有 DLNA 控制点、QPlay 发送端和连续播放场景的互操作认证；正式发布前请完成客户验收表。
